# Security Policy

## Supported releases

Security reports are accepted for the latest published release of Magic Hands.

## Reporting a vulnerability

Please do not publish an exploitable security issue, private information, or
proof-of-concept exploit in a public issue.

Use GitHub's **Report a vulnerability** feature under the repository's
**Security** tab if private vulnerability reporting is enabled. If it is not
available, contact the repository owner privately using the contact method
listed on their GitHub profile.

When reporting, include:
- the affected release version;
- your Windows version;
- a clear description of the issue and its impact;
- reproducible steps, where safe to provide.

Do not include passwords, personal images, private files, or other sensitive
data in a report.

## Scope

This repository distributes a compiled Windows application. Reports about
security vulnerabilities in the application or its distribution are welcome.
General usage questions and feature requests should be submitted as ordinary
GitHub issues.
